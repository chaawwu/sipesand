# Packages / UI

Kumpulan komponen visual reusable yang digunakan bersama di seluruh aplikasi SIPESAND:
- `SantriIdCard`: Studio perender dan preview KTS ISO CR-80 dengan 4 tema.
- `OfficialReceipt`: Generator cetak kuitansi dan faktur pembayaran dengan stempel QR.
- `LoginModal`: Modal login petugas & pengurus devisi.
- `AestheticToast`: Notifikasi pop-up non-intrusif.
- `DeveloperFooter`: Footer navigasi teknis King Digital Dev.
